# rank-explainer

Тема в одну строку → готовый mp4 1920×1080 + .srt. `${CLAUDE_SKILL_DIR}` — каталог скилла. Движок — студия `$STUDIO`: `$RANK_STUDIO`, иначе `~/rank-life-studio` (как её ищет `scripts/studio-path.sh`). Эпизод — это данные: `episodes/<ep>/episode.mjs`; всё сгенерированное лежит в `episodes/<ep>/cache/` (картинки, голос, куски видео) и пересобирается только при изменениях.

## Перед стартом
1. Нет студии → `bash ${CLAUDE_SKILL_DIR}/scripts/bootstrap.sh [dir]` (node ≥ 18, ffmpeg, Google Chrome или `CHROME_PATH`).
2. Ключ: `OPENROUTER_API_KEY` (картинки + голос) — в `$STUDIO/.env` (шаблон `.env.example`; скрипты читают его сами, он главнее переменных окружения) или в окружении. Ключ не печатать и не копировать в чат/файлы. Без ключа всё собирается с серыми заглушками и тихой дорожкой — так проверяют тайминг и карточки бесплатно.
3. Прочитай `references/style-guide.md` (формат, тон, кадр, промпты) и `references/pipeline.md` (формат episode.mjs, команды). Образец эпизода — `episodes/rome/episode.mjs`.

## Процесс
1. **Тема и лестница.** Уточни одним сообщением (или реши сам, если «на твой вкус»): иерархия и эпоха, длина (пилот 1–3 мин / полный 15–25 мин), сколько уровней (обычно 7–10). Составь лестницу рангов снизу вверх: название по-русски + короткое пояснение (`sub`). Покажи пользователю лестницу + логлайн героя до производства.
2. **Факты.** Ролик исторический: каждое утверждение должно быть проверяемым. Цифры (жалованье, сроки, нагрузки), названия, цитаты — только то, в чём уверен или что нашёл в источниках (WebSearch). Спорное — смягчай («по некоторым данным»), не выдумывай. Источники перечисли комментарием в начале episode.mjs.
3. **Сценарий** (`timeline` в episode.mjs). Рассказчик на «ты», настоящее время, сухая ирония, бытовые детали («каждый. божий. вечер»). Одна реплика `say` = один кадр, 12–30 слов (5–10 с). Структура: крючок (2–3 кадра) → обещание пути → `levelmap` → для каждого уровня `chapter` («Уровень первый. Тирон.») + 4–8 кадров (как попал, быт, деньги, опасности, как подняться выше) → финал. Темп рассказчика fish-audio ≈ 120 слов/мин (русские слова длинные): 20 мин ≈ 2300 слов ≈ 200 кадров; карточки и паузы добавляют ~10 %.
4. **Герой.** Один протагонист, который растёт по лестнице и стареет: `characters.hero` + варианты `from: 'hero'` на ключевых возрастах/рангах (одно лицо, меняются возраст, одежда, шрамы). Второстепенные — свои листы (центурион, жена, начальник). В кадр с героем передавай нужный вариант в `chars` — тогда лицо одно во всём ролике.
5. **Картинки.** `node images.mjs --ep <ep> --dry` — что и сколько будет сгенерировано. **Перед первой платной генерацией эпизода назови пользователю число картинок** (и стоимость, если уже известна по прошлым запускам: images.mjs печатает `$` за штуку). Порядок: сначала только персонажи (`--only char:hero,…`), посмотри листы (Read PNG из `cache/img/`), поправь промпты; потом обложки уровней и кадры (`--max` под объём). Плохой кадр — правь промпт или поставь `v: 2` в его `img` и перегенерируй только его.
6. **Голос.** `voice.narrator` — id голоса fish.audio (каталог: `curl -s "https://api.fish.audio/model?page_size=40&language=ru&sort_by=task_count"`; голоса-двойники реальных людей не брать). `node voice.mjs --ep <ep> --check` — TTS только новых реплик + сверка speech-to-text.
7. **Сборка и ревью.** `node render.mjs --ep <ep> --preview --contact` → `out/<ep>_preview.mp4` + контакт-лист (кадр из середины каждого куска): смотри его сам (Read), проверь, что кадры соответствуют тексту, лица совпадают, нет текста/артефактов на картинках. Быстрая проверка куска — `--from <id> --to <id>`.
8. **Финал:** `node render.mjs --ep <ep> --contact` → `out/<ep>.mp4` (1920×1080, 30 fps, AAC) + `out/<ep>.srt`. Проверь ffprobe и отдай пользователю (SendUserFile) mp4 + srt + список кадров, которые стоит перегенерировать, если такие остались.

## Частые ошибки
- Анахронизмы: нейросеть любит надевать пожилым писарям и лекарям ОЧКИ, ставить средневековые решётчатые окна и книги-кодексы. Для эпох до Нового времени впиши в `style` с самого начала «no eyeglasses, no modern objects» (добавлять потом дорого — стиль входит в ключ всех картинок); единичный промах — уточни промпт кадра («a bare face, no glasses»).
- Текст на картинках (вывески, подписи, «пузыри») — нейросеть пишет абракадабру. В промпте не проси надписей; STYLE_TAIL уже запрещает текст — если всё равно появился, перегенерируй (`v: 2`).
- Лицо героя «плывёт» — в `chars` не передан лист героя, или в сцене с двумя персонажами не сказано, кто где («the bearded craftsman in the foreground…»).
- Реплика длиннее ~35 слов → кадр висит 12+ с. Разбей на две реплики с двумя кадрами (или `img: [ {…}, {…} ]` — одна реплика, две картинки пополам).
- Реальные узнаваемые лица (диктаторы, политики) — только как исторические фигуры в нейтральном/сатирическом контексте, без пропаганды и без героизации преступлений; символику не делать центром кадра.
- Не копировать чужие каналы: свой герой, свои формулировки, своя лестница. Формат «жизнь на каждом ранге» — жанр, а не чужой контент.
- Деньги: никаких циклов по API; кэш по хэшу промпта — не меняй промпты без нужды (правка промпта = новая картинка = новые деньги).
